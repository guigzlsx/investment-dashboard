# Modèle de données

Le modèle est volontairement non implémenté à ce stade. Il sera arrêté avant l’ajout de Supabase/PostgreSQL.

## Entités à étudier

- utilisateur ou compte ;
- portefeuille ;
- actif financier ;
- transaction ;
- position ;
- valorisation historique ;
- dividende ou autre flux ;
- source et horodatage des données de marché.

## Points à clarifier

- identifiants et contraintes d’unicité ;
- devise de référence et conversions ;
- gestion des frais, taxes et opérations sur titres ;
- historique immuable des transactions ;
- précision numérique et règles d’arrondi ;
- séparation des données privées et des données de référence.
